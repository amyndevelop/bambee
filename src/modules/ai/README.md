# Integración futura, deshabilitada

BAMBEE 0.1.0 no llama a proveedores de IA. No se envían imágenes ni datos médicos para entrenamiento o inferencia.

Un futuro adaptador se habilitará solo con consentimiento separado versionado en ConsentRecord, selección explícita de registros, minimización y auditoría. La búsqueda educativa debe limitarse a WeeklyDevelopment publicado y revisado, conservar las referencias y mostrar incertidumbre. Ningún adaptador podrá interpretar imágenes de ecografías, inferir salud fetal por fotografías o emitir diagnósticos. Requiere evaluación de privacidad, proveedor, retención y revisión profesional antes de habilitarse.

La progresión de pancita conserva fotos originales privadas y orden temporal. La exportación de video no forma parte de esta versión.
